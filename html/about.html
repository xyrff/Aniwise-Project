Supporting Smarter Agriculture

AniWise is a smart agriculture support system designed to help users explore data-informed crop decisions. It combines machine learning-powered recommendations and yield estimates with current weather information, making essential agricultural insights easier to access in one place.

How the product is built

Our Technology

AniWise combines a crop recommendation form, a prototype yield workflow, and a live Open-Meteo forecast so users can see what is connected before they make a decision.

  • Machine learning workflow
  • Weather API integration
  • Data-informed decisions
  • JavaScript web interface

What each tool does

Models and features used

Crop Recommendation System

Collects soil and environmental inputs so a connected model can rank crop options for the given conditions.

Yield Prediction System

Provides the input workflow for a future yield estimate. The prediction service is clearly marked as pending.

Weather Forecast

Uses a weather API to show current conditions, a 7-day forecast, and a practical insight for the selected location.

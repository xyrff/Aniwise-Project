Supporting smarter agriculture

AniWise is a smart agriculture support system designed to help users explore data-informed crop decisions. It combines machine learning-powered recommendations and yield estimates with current weather information, making essential agricultural insights easier to access in one place.

Our Technology

AniWise combines data-driven machine learning models with weather API integration to turn agricultural inputs into clear, practical insights for crop planning and decision-making.

  • Machine Learning Models
  • Weather API Integration
  • Data-Driven Insights
  • JavaScript Web Interface

Machine Learning Models & Features Used

Crop Recommendation System

This machine learning model analyzes relevant soil and environmental inputs to recommend crop options that may be suitable for the given conditions.

Yield Prediction System

This machine learning model estimates potential crop yield from available agricultural inputs, helping users plan and evaluate expected production.

Weather Forecast

Not a machine learning model. This feature uses a weather API integration to provide current weather data and forecasts for the selected location.
